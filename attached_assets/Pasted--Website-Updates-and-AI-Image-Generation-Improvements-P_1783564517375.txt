# 4. Generate a Character Reference Sheet

Immediately after creating the Character Profile, generate a *Character Reference Sheet* for each uploaded child.

The Character Reference Sheet should serve as the canonical visual representation of the child for the remainder of the story.

It should:

•⁠  ⁠Use the Character Profile as its source.
•⁠  ⁠Clearly depict the child's face and appearance.
•⁠  ⁠Match the exact illustration style used throughout the storybook.
•⁠  ⁠Show the child's natural hairstyle, hair color, facial features, skin tone, eye color, freckles, glasses (if applicable), and other defining characteristics.
•⁠  ⁠Avoid costumes, exaggerated expressions, unusual poses, or scene-specific styling.
•⁠  ⁠Focus on accurately representing the child's normal appearance.

This Character Reference Sheet should be retained and reused internally throughout the story generation process.

Every subsequent illustration should be generated using:

1.⁠ ⁠The current page's scene description.
2.⁠ ⁠The child's Character Profile.
3.⁠ ⁠The child's Character Reference Sheet.

The Character Reference Sheet should act as the canonical visual reference for maintaining facial consistency, reducing appearance drift, and ensuring the child remains recognizable across every page.

If the image generation workflow supports image references, use the Character Reference Sheet as a reference image when generating subsequent illustrations.
